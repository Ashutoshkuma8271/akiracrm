# Akira Fresh CRM & Cold-Chain Management

A full-stack enterprise CRM and Cold-Chain Operations Platform for Akira Fresh, built with React, Vite, and designed for instant Vercel deployment.

## Features

- **Executive Overview**: Real-time sales metrics, product mix breakdown, live Delhi NCR Cold Hub status (-18°C SLA), and AI retention recommendations.
- **Customer Directory**: Complete CRM with segmentation (VIP, Repeat buyers, New, At risk), order histories, notes, CSV import/export, and direct WhatsApp launcher.
- **Cold-Chain Orders**: Live order lifecycle tracking (Placed, Packing, Cold-Chain Transit, Delivered), order builder, free delivery automation (>₹499), and printable tax invoices with FSSAI certification.
- **Product Mix & Inventory**: Recipe management, batch stock tracking, flash sales, and low-stock alerts.
- **WhatsApp & Email Campaigns**: Retention marketing with dynamic merge tags, promo code generator, and direct WhatsApp web integration.
- **Logistics Telemetry**: Sub-zero temperature telemetry for Delhi NCR hubs (Gurugram, South Delhi, Noida, West Delhi).

## Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

1. Import this repository in Vercel.
2. Framework Preset: **Vite**.
3. Build Command: `npm run build`.
4. Output Directory: `dist`.
5. Deploy!

## Local Development

```bash
npm install
npm run dev
```
